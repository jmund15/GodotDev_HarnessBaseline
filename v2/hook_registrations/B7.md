B14 folds these rows into `/v2/hook_registrations.md`; S8 and S9 write `settings.json` from it. Both rows run one shared file, `hooks/compact_directive_anchor.py`, which dispatches on the payload's `hook_event_name`.

| Event | Matcher | Command | Timeout (s) | Purpose |
|---|---|---|---|---|
| SessionStart | `compact` | `python3 "$CLAUDE_PROJECT_DIR/.claude/hooks/compact_directive_anchor.py"` | 15 | Prints the session's state file (`.claude/work/<slug>.md`, via the pointer `.claude/scratch/active_state_<session_id>`) after a compaction. No pointer, no output. |
| PostToolUse | `Write\|Edit` | `python3 "$CLAUDE_PROJECT_DIR/.claude/hooks/compact_directive_anchor.py"` | 15 | Writes the pointer when the written file is a state file, so the writing session's next compaction re-prints it. Other paths write nothing. |
