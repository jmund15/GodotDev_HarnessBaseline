# Hook registration from B7 (the compact hook)

B14 folds this row into `/v2/hook_registrations.md` (row 16); S8 and S9 write `settings.json` from it. It runs one shared file, `hooks/compact_directive_anchor.py`, which dispatches on the payload's `hook_event_name`.

| Event | Matcher | Command | Timeout (s) | Purpose |
|---|---|---|---|---|
| SessionStart | `compact` | `python3 "$CLAUDE_PROJECT_DIR/.claude/hooks/compact_directive_anchor.py"` | 15 | Prints the session's state file (`.claude/work/<slug>.md`, via the pointer `.claude/scratch/active_state_<session_id>`) after a compaction. No pointer, no output. |

The pointer write is not a registration: a Write or Edit of a state file reaches `compact_directive_anchor` as a `post_edit` member of `post_edit_dispatch.py` (`_chain.EVENTS`). A project that registered the v1 PostToolUse entry for this file removes it at cutover.

Replaces the v1 owner-directive anchor rows (`settings.base.json` lines 271 and 276: `SessionStart` `compact`, with and without `--opening`). The v1 rows for `compact_directive_ledger.py`, `subagent_compaction_rail.py` (`settings.base.json` lines 130, 135, 281) and `sidecar_recompact_reprompt.py` (line 286) have no successor here; their hooks are deleted, and S8 and S9 drop the rows when they write `settings.json`.

The 15 s timeout matches the value `scripts/codex_proxy_sidecar.sh` already uses for its compact hook.
