# Carried/dropped: A5 (`/review`)

`/review` (`template/.claude/commands/review.md`) replaces `/plan_check` and `/session_audit`. A5 removed no always-loaded rule, so every row here is a phase or a rule of a merged file. **Carried** names where it went. **Dropped** says what dropping it does for later efficiency and flexibility (E2); "its tool is deleted" is never the whole reason.

Source files: `commands/plan_check.md`, `agents/plan_check_agents.md`, `reference/plan_check_detail.md`, `commands/session_audit.md`, `agents/session_audit_agents.md`, `reference/session_audit_parity.md`, `reference/session_audit_seats.md`, `agents/review_agents.md`, `agents/review_fold.md`, and `checklists/known_failure_modes.md` (Q4).
