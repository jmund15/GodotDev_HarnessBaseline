# Carried/dropped: A10 (command deletes, reshaped setup commands, kept-command sweep)

A10 removed no always-loaded rule. Each row is a deleted command, or a phase or rule a kept command lost or moved. **Carried** names where it went. **Replaced** names the v2 mechanism that does the job. **Moved** names a home outside the shared repo. **Dropped** says what dropping it does for later efficiency and flexibility (E2); "its tool is deleted" is never the whole reason. Paths are below `template/.claude/`.
