# Carried/dropped: A3 (delegate rails and the two brief shapes)

A3 replaces the v1 per-shape guard files with one rails file, `guards/rails.md` (3,060 B, rulings Q7), and rewrites `skills/orchestration/reference/brief_checks.md` into the open and execute brief shapes (T4). **Carried** names where the rule now lives. **Dropped** says what dropping it does for later efficiency and flexibility (E2).

Sources: the shared `guards/common.md`, `author.md`, `review.md`, `survey.md`, `gate.md`, `author.coding.md`, `survey.coding.md`, `common.godot.md`, `author.godot.md` and `survey.godot.md` at `v2` `b8e046c`; PushinPotions' forked `common.md` and `author.md` and its local `arm.md` (`origin/main`); MaddManager's `any.md` (its copy of `common.md`, with two more rules); and `brief_checks.md`. Each rail is read from its `## detailed` tier, which is the superset of the others.

## The rail mechanism

| v1 rule | Mark | Where, or why |
|---|---|---|
| Three tiers per file (`detailed`, `condensed`, `minimal`) chosen per receiving model (`railTier`) | dropped | Rail tiers go with the registry (V7). One text for every model means one review and no per-model drift: the v1 tiers had already diverged (the `minimal` wait line lacked the 30-minute hand-back's reason). |
| `common` plus a per-shape file (author, review, survey, gate), plus `coding` and `godot` layer overlays, assembled by `tools/guard_text.py` | dropped | One file, `guards/rails.md`, which the launcher and the engine pass whole (Q7). One path per job removes the assembly code, its overlay lookup and the three routes that each re-delivered it. |
| "Read only the section your dispatch names"; "every line cites its home; the home wins" | dropped | One flat file has no sections to pick. The rails cite a home only where the delegate needs to read it (`claim_confidence.md`, `CLAUDE.core.md` §Shell Discipline). |
| The ai-worker clause rendered against this machine | dropped | The routing to `ai-worker` is the user's global instruction, which every delegate on that machine already loads. A shared file then never names a tool a machine may lack. |
