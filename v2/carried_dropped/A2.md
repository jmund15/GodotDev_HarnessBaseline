# Carried/dropped: A2 (`orchestration`, model table, capacity line, `/delegate`)

A2 rewrote `skills/orchestration/SKILL.md` (20,003 B to 10,140 B) and `commands/delegate.md` (10,523 B to 4,726 B). It deleted sixteen `skills/orchestration/reference/` files and `commands/agents/orchestrator_action_protocol.md`. `reference/brief_checks.md` is A3's. No file A2 owns is always-loaded, so every row is a section or rule of a rewritten or deleted file, plus the three always-loaded rules A1 handed to A2. Paths are below `template/.claude/`. **Carried** names the v2 line. **Dropped** says what dropping it does for later efficiency and flexibility; "its tool is deleted" is never the whole reason.

Inputs: the lane's `v2` bytes, which equal MaddManager's. PushinPotions' `origin/main` copies of `SKILL.md`, `delegate.md` and the protocol differ only in v1 machinery wording (`review_fanout.js` naming, `tool_profiles.py` `RESERVED_BUILTINS`, the judged-job rule moved into `brief_checks.md`), none of which v2 keeps. None of these files is `forked` in either lock.
