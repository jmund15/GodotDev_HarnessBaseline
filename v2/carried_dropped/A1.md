# A1 — carried/dropped rows: always-loaded v1 rules, `rules/harness_tooling.md`, A1's reference files

One row per v1 rule unit (a bullet, a paragraph rule or a table row). **Carried** names where the rule now lives, and its reason travels with it there. **Moved** names the v2 unit (and the S6 lane writing it) that owns the decision, because only that unit's moment needs it. **Dropped** gives what dropping it does for later efficiency and flexibility (E2). Sources were read at PushinPotions `origin/main` (`.claude/CLAUDE.core.md`, PushinPotions' M1-forked bytes, which differ from the template in four lines and are the base here), the shared template (`CLAUDE.coding.md`, identical in all three trees), PushinPotions `CLAUDE.md` and `CLAUDE.godot.md`, and MaddManager `main` `CLAUDE.md`.

A general forward reason applies to every core cut and is not repeated per row: the core is paid on every call of every session in both repos (T2), so each byte removed from it is saved on every future turn, and a shorter standing set keeps each remaining rule's reason readable.
