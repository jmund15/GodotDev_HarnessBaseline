# Guard: survey — read/search/discovery delegates

Read ONLY the section your dispatch names; if none is named, read `## detailed`. `any.md`'s section of the same tier binds you too and arrives with this file. Every line cites the home that owns it; the home is authoritative if this summary and it ever disagree.

## detailed

- **Blast-radius claims carry the evidence that produced them.** Your ceiling is **read (swept)**: you opened each hit and confirmed it is a use, not a declaration or a comment, and you also covered the reference classes a code-only search cannot see — asset and scene references, script paths, UIDs, data keys, signal names. **observed** — you ran it and watched the failure — is yours for a `.claude/tests/` proof and for any run `any.md`'s single-flight bar does not name. Under a declared concurrent dispatch, a run that bar names is the orchestrator's; report it as the caller's next step. Any weaker claim names its rung in the claim: traced, pattern or matched (`claim_confidence.md`). An exhaustive enumeration only a language server can settle (every caller, every override) is a GAP you report, not a number you estimate: an estimated count reads as an enumerated one and is worse than the admitted gap. [reference/claim_confidence.md]
- Grep stays correct for literal field values, UID hashes, regex alternation, attribute markers, comment scans, `using` directives, and declaration anchors. [CLAUDE.core.md §9]
- **An absence claim carries its git check as evidence.** Return `{"command": "git grep -n <pattern> <branch> -- <path>", "output": ""}` (likewise `git ls-tree`, `git check-ignore -v <path>`, `git branch -a`); the parent's claim check runs it. An empty Grep/Glob is NOT evidence of absence. Check unmerged branches for every absence claim; for other claims, when they extend beyond the worktree or evidence says the feature shipped elsewhere. [gotcha_survey_absence_feature_lives_on_unmerged_branch.md]
- **A gitignored path has no verifying git command.** Glob rooted inside the ignored directory: an empty result counts only after a Glob for a known-present file in the same root returns that file, and the claim reaches the parent as unchecked, so the parent reads the source. [gotcha_gitignore_build_glob_swallows_production_dirs.md]
