# Asset Provenance — sourcing rules and the ledger contract

The pipeline already enforces a ledger: `icon_spec.json` `source != "procedural"` requires a
`CREDITS.md` entry, and `templates/conform_external.py` ends in a mandatory ledger write. This file
owns the decisions that feed it — what may be sourced, what the entry must record, and which
obligations survive the transformations the pipeline performs.

Scope: any asset entering the repo that was not generated by this pipeline. Sprites, textures,
tilesets, audio, fonts, impulse responses.

## Decision rules

1. **"Free", "royalty-free", "no attribution required", search-engine-visible, and
   model-generated are not licenses.** A license is a named instrument (CC0-1.0, CC-BY-4.0, OFL-1.1,
   a vendor EULA) attached to the specific asset. Prose terms in a listing description are a claim
   about a license, not one. Absent a named instrument, the asset does not enter the repo.
2. **Record provenance at acquisition, not at ship.** The tab you found it in is the only moment the
   source URL, license, and author are cheap to capture; a committed `.png` carries none of them.
3. **Attribution obligations survive transformation.** Posterizing, palette-conforming, atlas
   packing, renaming, format conversion, and derivative edits do not discharge a CC-BY term. Atlas
   packing is where the link is silently lost, because the output is one file with no author —
   which is exactly why the ledger is keyed on the *source* asset, not the packed artifact.
4. **Shipping a game and publishing its source assets are different permissions.** This repo is
   public and carries both. A marketplace license may permit the binary and forbid redistributing
   the editable source. Check the redistribution clause separately from the use clause; a license
   that clears one does not clear the other.
5. **Model-generated assets carry their generator's terms plus their training-input risk**, and
   inherit no license from the prompt. Treat as unlicensed unless the generator's terms grant
   commercial use in writing.
6. **Unclear is a verdict, not a state to resolve later.** Park the asset outside the repo until the
   instrument is named — "later" arrives after it has been conformed and packed into an atlas,
   which is the point rule 3 says the link is already gone.

## Ledger entry — required fields

Every non-procedural asset gets a `CREDITS.md` row. Missing any field means the row is incomplete,
which the bake treats the same as absent.

**One ledger per asset-domain root, at that root** — `Audio/CREDITS.md` covers everything under
`Audio/`. A per-domain ledger stays next to what it describes and survives a folder move; a single
repo-wide one drifts because nothing forces a writer past it. `Audio/CREDITS.md` is the worked
example.

| Field | Why it is required |
|---|---|
| `asset` | Path as committed, post-conform. Joins the ledger to what actually ships. |
| `source_url` | Where it was acquired. Corroboration for the identifier. |
| `license` | SPDX-style identifier (`CC0-1.0`, `CC-BY-4.0`, `OFL-1.1`, `vendor-EULA:<name>`). Never a prose phrase. |
| `author` | Required even under CC0, where attribution is optional — you cannot re-decide an optional courtesy you failed to record. |
| `acquired` | ISO date. Bounds which version of the terms applied. |
| `redistribution` | `source-ok` / `binary-only` / `unknown`. Rule 4; `unknown` blocks the source-asset commit. |
| `transforms` | What the pipeline did (posterize, conform, atlas). Rule 3's audit trail. |

## Verified sources

Endpoints below were fetched live and confirmed **2026-08-12**; counts are from those responses.
Re-verify before treating a count or a filter as current — this table is a snapshot, and its
predecessor's Poly Haven figure had already drifted 788 → 847 when checked.

| Source | Endpoint | License posture | Verified |
|---|---|---|---|
| Poly Haven | `api.polyhaven.com/assets?t=textures` | CC0-1.0 | 200, **847** texture assets |
| ambientCG | `ambientcg.com/api/v2/full_json` | CC0-1.0 | 200, **2,877** results; paginate via `nextPageHttp` |
| Freesound | `freesound.org/apiv2/` (free API key) | Mixed — filter required | 200; `license` is an exact-match string |
| OpenGameArt | `opengameart.org` | Mixed, per-asset | 200 |
| EchoThief | `echothief.com` | CC0 impulse responses | 200 |
| Free Music Archive | `freemusicarchive.org` | Mixed, per-track | 200 |
| Sonniss GDC bundles | `archive.org/details/sonniss.com-gdc-game-audio-bundles` | ⚠ prose terms only — see below | 200, 82 files |

**Freesound is mixed-license, so the filter is load-bearing:**
`filter=license:"Creative Commons 0"`. The API's `license` field takes exactly `"Attribution"`,
`"Attribution NonCommercial"`, or `"Creative Commons 0"` — an unfiltered search returns
attribution-bearing sounds indistinguishable from CC0 ones at download time. The API also exposes
`gen_ai_preference`, an uploader-set flag on generative-AI training use; it does not affect game
use, but it is the field to read if that ever matters.

**Sonniss is the worked example of rule 1.** The archive item's metadata has **no `licenseurl`
field**. Its terms exist only as prose in the description — *"royalty free and commercially usable.
No attribution is required"*. That is a claim about a license, not a license. It is usable, but the
ledger entry records `vendor-EULA:Sonniss-GDC` with the archive URL, never `CC0-1.0`.

Named dead ends, so they are not re-investigated: ShapeNet, Poly Pizza, BlenderKit, BBC Sound
Effects, AMASS. Sonniss's own `sonniss.com` links Cloudflare-block headless fetches — use the
archive.org mirror above.

Endpoint and metadata checks go through `.claude/scripts/fetch_source.sh` (CLAUDE.md §4 fetch
order): a login wall or bot challenge returns a **200 body** that reads as content to anything that
does not inspect it, and refusing those is the one guarantee this table depends on.

## Reading the license — match the instrument URL, not the prose

A keyword scan of the page misreads it in both directions. Measured against three
correctly-licensed OpenGameArt items: a pattern for `CC0 1.0` matched none of them (the page renders
bare `CC0`), and a scan for licence words matched "Attribution" out of a *collection name*, flagging
a CC0 asset as attribution-bearing.

Match the canonical instrument URL, which is unambiguous where the prose is not:
`creativecommons.org/publicdomain/zero/1.0/` (CC0), `creativecommons.org/licenses/by/4.0/` (CC-BY).
A search filter that surfaced the page is not evidence either — verify on the item itself.

## Access and formats

**Freesound requires a key.** Anonymous calls return `401
{"detail":"Authentication credentials were not provided."}`. The key lives **outside the repo** at
`~/.config/freesound/api_key` — never in the tree, never in a `.tres`, never in a commit:

```
curl -H "Authorization: Token $(cat ~/.config/freesound/api_key)" \
  'https://freesound.org/apiv2/search/text/?query=impact&filter=license%3A%22Creative%20Commons%200%22&fields=id,name,license,username,duration,channels,samplerate,type,tags'
```

Request `fields=` explicitly — it returns every ledger field plus `tags` and `duration` in one call,
which is why Freesound beats scraping an HTML listing. **Query terms AND together**: three or more
words routinely returns `count: 0`. Start with two and widen the duration filter, not the wording.

**Archives and audio formats:**

- `7z.exe` is installed at `C:\Program Files\7-Zip\7z.exe` but is **not on `PATH`** — `command -v 7z`
  reports it absent, which reads as "cannot extract" and silently drops every `.7z` candidate. Call
  it by full path.
- **Godot 4 imports WAV, Ogg Vorbis, and MP3 — not FLAC.** A FLAC pack needs conversion before use,
  and that conversion is a rule-3 transform, not a free step.
- **`AudioStreamPlayer3D` spatializes mono.** A stereo source does not pan positionally, so any
  positional SFX needs a mono downmix — again a rule-3 transform.

## Audition — the gap this pipeline does not close

`sprite_authoring` mandates a render→screenshot→critique loop because the agent must *see* the asset
before judging it. **There is no audio equivalent — the agent cannot hear.** Do not let objective
measurement pass itself off as an audition:

| Decidable from metadata (agent's call) | Requires listening (user's call) |
|---|---|
| Duration — a one-shot past ~500 ms smears when the event repeats fast | Timbre and character |
| Channels — mono vs stereo, per the 3D rule above | Whether it fits the game's tone |
| Sample rate and format — engine support, file size | Whether it reads as the right material |
| Tags and description — a coarse semantic filter | Whether it sits right against the other sounds |

Shortlist on the left column, then hand the candidates to the user for the right one. A sourced
sound is a **placeholder until someone has heard it**, and the ledger row is valid either way.
