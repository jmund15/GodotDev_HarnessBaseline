# Writer-delegate returns

Read when briefing or consuming a delegate that writes (`orchestration` §4 points here).

- A delegate that writes returns a `choices` block, one `{unit, why}` row per unit whose content its brief or plan does not state; an empty block claims none, and a missing one fails `check --block choices=unit,why`. Review routes those units per [`later_rounds.md`](later_rounds.md).
- A delegate writes its report to the file its brief names (`<spillDir>/<label>.md`) before its turn ends. Capture keeps that file as the delivery and sets a later final message aside as `<label>.reply.md`. With no such file the final message is the delivery, and capture warns when the stream shows it answered a later turn.
- A delegate that changes gated code returns a `reach` block, and its brief asks for it: one `{owner, domains}` row per shared owner it changed (a base class, autoload, factory default, shared fixture or helper, submodule type), with the test domains whose tests call it, named as the lane-close scope run takes them. An empty block claims none, and a missing one fails `check --block reach=owner,domains`. The dispatcher unions the lane's blocks into the lane-close scope (`change_control` §Gate cadence).
- A delegate that writes in the shared main checkout never commits: it returns `changedPaths` as one deliverable line holding a JSON list (`changedPaths: ["a.py", "b.py"]`; `dispatch_result.py consume` reads it), and its dispatcher commits them. The client's git instructions tell a model on the default branch to branch first, and a branch switch in the shared checkout moves every peer's work. A delegate in a worktree on its own branch commits there.
- A delegate cannot ask the owner. It applies a cleanup only when it is in-file, behavior-preserving, inside its brief's write set and changes no contract; it returns every other cleanup it notices in an `offers` block. An `offers` block contains the finding, `path:line` evidence, change, cost and recommendation. An empty block claims none. The parent re-checks an offer before relaying it into the owner's question packet.
