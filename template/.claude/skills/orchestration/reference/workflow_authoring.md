# Authoring a Workflow on the fly

Read before writing a new Workflow script (`orchestration` §9 points here).

Use the `workflow-authoring` reference and prefer the existing engines. A new script has literal metadata, explicit pins, PINS logging and schemas for machine-read results. The PINS value is the launch record: `model/effort/agentType tier:<t>`, plus the job's `pick:<p> spec:<s>` when it states them (`orchestration` §5) — an engine that logs the pin without them leaves the reason unrecorded for every reader. A script fills no omitted pin: every job carries its caller's model and effort, a step the script starts itself takes a caller pin, and only a step whose output the script checks mechanically runs on `args.checker` (`orchestration` §5 *Effort*). Write-shaped schemas carry `couldNotSatisfy` and `choices` ([Agent Prompt Structure](../SKILL.md#4-agent-prompt-structure)), plus `redVerification` on TDD stages. Use `pipeline()` unless a stage needs every prior result. Pass paths and short scalars, never giant args, and declare any discovery coverage cap and run budget. A machine-read schema carries no `maxLength` and no `maxItems` on a findings array: a violation discards the whole completed result, so bound output in the prompt. Keep field descriptions short, because a schema too large to classify is rejected at dispatch. An empty discovery result follows the absence rule in `guards/survey.md`; consume its verification per `commands/agents/orchestrator_action_protocol.md` Step 1.5. A script whose result holds findings, claims or verdicts embeds the CLOSE-CHECK and EVIDENCE-SSOT blocks and returns `verification` (`orchestration` §8); any exempt script carries one `// POST-CHECK exempt (<class>): <reason>` line after its metadata, using the census classes enforced by `test_native_caller_contracts.py`. Write each agent prompt inside the script as a template literal and pass `args` only as short scalars (a path, a token, a count), because a large multi-line `args` can fail the permission handler's control-character check; parse `args` tolerantly, since it may arrive as a string. Evidence: `gotcha_workflow_args_permission_control_chars`. On resume, keep completed results and inspect a missing one before re-dispatch.
