# Retrieving a dispatch's full result

Read when consuming a Workflow or native job's result (`orchestration` §4 states the return contract).

- **A Workflow result's complete set:** capture `transcriptDir` from the result and run `python3 .claude/tools/session_digest.py --workflow-dir <transcriptDir> --workflow-kind <explore|review> --workflow-manifest`, then `--workflow-select <ID>`, `--workflow-page {items,lenses,reports,gaps,merges} --page <N> --page-size <N>` or `--workflow-full`, each with `--expect-journal-sha256 <hash from the manifest>`.
- **A Workflow deliverable file:** a job with Write and `spillDir` writes `<spillDir>/<label>.md`. A job without Write or without `spillDir` returns its full deliverable inline in the journal. The parent materializes it with `python3 .claude/tools/dispatch_result.py <transcriptDir>`. Add `--out-dir <directory>` when the run record has no `spillDir`. The client refuses a native agent's Write of a separate report file (a `report.md` drew "Subagents should return findings as text, not write report files"), so a native brief puts its report in `<spillDir>/<label>.md`; data files it names (a `findings.json`) still write.
- **A read-only sidecar job that compacted:** a job with no Write tool cannot save findings before its context compacts, so the launcher's hook copies each continuation summary to `<record>.compaction.md` beside the record. When such a job ends without its answer (a breaker, a kill, a summary stored as the deliverable), read that file before another dispatch; its first line counts the summaries it holds.
- **A review seat whose structured return failed:** the seat's findings live in `<brief>.findings.jsonl`, one row each, recorded by `tools/seat_findings.py add` as it settled them; the review tail reads them in place of the return (`reference/sidecar_dispatch.md` review panel).
- **A script-parsed result:** its fenced JSON Lines blocks are validated by `dispatch_result.py check <spill.md> --block <name>=<key,key...>`. The delegate runs it when its profile has Bash, else the parent runs it before reading a row.
