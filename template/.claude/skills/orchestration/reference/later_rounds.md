# Later review rounds

Read before seating a review of a subject an earlier round reviewed (`orchestration` §2 *Later rounds* points here).

Rigor sets which findings owe a round: a unit that answers only a finding below the run's bar owes no re-check ([`rigor.md`](rigor.md)); the other triggers in this file stand, and every later-round seat is told the same bar. Rounds repeat until coverage is complete, every counting finding has a disposition and no supported critical stands; no count limits them.

Check each changed unit at the least that catches its defects, and state the choice and why. A change the session can read whole against its finding and the mandates that cite it, the session reads and records (`review_ledger.py record --inline <who> --mandate <m>`), its own edits included. The exception is the session's own design edit to standing harness text, or any own design edit at thorough rigor: it gets a seat, because an author misses defects in its own design. Remove this exception when such seats find no held defect across several drives. A seat only where a read cannot judge the change: it reaches units or citers beyond itself, or its defects hide where one pass misses them. Size a seat's width by how many units changed, their kind and how widely cited, and its depth by how deep defects can hide. A plan's measure is the post-check's `nextRound.change`: `changedUnits`, the unchanged units each one `reach`es and the mandates whose findings cite them. `fold_check.py --measure <reviewed copy> <current>` measures the session's own design edits, which no fold record holds. Code's measure is `git diff <reviewed head>..HEAD` plus the consumers `findReferences` reaches from changed symbols. Fixes that rewrote the core design, a decision most unchanged units depend on, get the full panel again with `--ignore-ledger` on `plan`. Route each changed unit by who wrote its design. A later-round seat reads the full subject and reviews only its units:
- **A reviewer's own fix or recommended option:** a verified finding applied exactly as its `old`/`new` pair states records done: `post_check.py` records it, and no seat re-reviews it. If an applied recommended option adds facts or changes a seam, contract, home or file list, check only those additions and changes for grounding and coherence.
- **Design no reviewer saw:** a change written in place of the finding's fix or options, conflicting fixes from separate seats on one unit, an owner answer, or a delegate's `choices` ([`writer_returns.md`](writer_returns.md)). Check those units against the mandates whose findings cite them (for `choices`, the command's design mandates), plus grounding and coherence.

A mandate left uncovered or failed re-runs over the whole subject. A supported critical inside a remedy a fold already applied gets the smallest remedy the existing design carries, checked against the original finding and the remedy's citers; when only added design answers the finding, halt as non-convergence (drive halt H5). A later-round seat is a clean context: it receives the revised subject and never an earlier round's findings or ledger, which would steer a seat meant to judge fresh. The revised subject carries each disposition's rationale inline, and the orchestrator dedups the seat's findings against its own earlier-round ledger and escalates only a new finding or one the inline rationale does not answer. A fact check is not a round. A unit the plan states and the delegate transcribed gets correctness checks (tests, diff read), not a second design review.
